# ગોલ આધારિત રોકાણ ફોર્મ (Gujarati Goal-Based Investment Form & Planner)

આ એપ્લિકેશન રોકાણકારો માટે ગુજરાતી ભાષામાં તેમના નાણાકીય લક્ષ્યો (Financial Goals) નું વિશ્લેષણ કરવા અને યોગ્ય માસિક SIP રોકાણની ગણતરી કરવા માટે બનાવવામાં આવી છે.

---

## મુખ્ય વિશેષતાઓ (Key Features)

1. **સંપૂર્ણ ગુજરાતી પ્રશ્નાવલી (Gujarati Questionnaire):**
   - રોકાણકારની વિગતો (નામ, મોબાઈલ, ઉંમર, વ્યવસાય, વાર્ષિક આવક)
   - ૬ મુખ્ય નાણાકીય લક્ષ્યોના વિકલ્પો (શિક્ષણ, લગ્ન, ઘર, રિટાયરમેન્ટ, વાહન, વેલ્થ ક્રિએશન)
   - લક્ષ્યની રકમ, સમયગાળો અને હાલની બચત
   - જોખમ ક્ષમતા (Conservative, Moderate, Aggressive)
   - રોકાણ પસંદગી (Monthly SIP, Lump-sum, Step-up)

2. **સ્માર્ટ ફાઇનાન્સિયલ કેલ્ક્યુલેશન (Smart SIP & Inflation Engine):**
   - ૬% વાર્ષિક મોંઘવારી (Inflation) આધારિત ભવિષ્યની લક્ષ્ય રકમની ગણતરી.
   - હાલની ઉપલબ્ધ બચતનું ચક્રવૃદ્ધિ મૂલ્ય બાદ કરી ચોક્કસ જરૂરી માસિક SIP ની ગણતરી.
   - રોકાણકારની માસિક બચત ક્ષમતા અને જરૂરી SIP વચ્ચેનું સરખામણી વિશ્લેષણ (Budget Gap Analysis).

3. **પ્રિન્ટ અને પીડીએફ સપોર્ટ (Print / Save as PDF Ready):**
   - માત્ર એક ક્લિકથી રોકાણકારને આપવા માટે A4 સાઇઝનો સુંદર રિપોર્ટ પ્રિન્ટ અથવા પીડીએફ તરીકે સેવ કરી શકાય છે.
   - સલાહકાર અને રોકાણકારની સહી (Sign-off) ની વ્યવસ્થા.

4. **૧ વપરાશકર્તા દીઠ ૧ સબમિશન (One-Time Use Per User):**
   - રોકાણકાર ફોર્મ સબમિટ કરે તે પછી ડુપ્લિકેટ એન્ટ્રી અટકાવવા માટે ફોર્મ લૉક થાય છે અને તેમનો પ્લાનિંગ રિપોર્ટ સેવ રહે છે.
   - મોબાઈલ નંબર અને બ્રાઉઝર સેશન દ્વારા ડુપ્લિકેટ સબમિશન પર પ્રતિબંધ.
   - **એડવાઇઝર અનલોક:** એડવાઇઝર `Ctrl + Shift + M` દબાવીને માસ્ટર ડેટાબેઝમાંથી **"નવા યુઝર માટે ફોર્મ અનલોક કરો"** બટન દ્વારા નવા ક્લાયન્ટ માટે ફોર્મ અનલોક કરી શકે છે.
